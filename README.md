## 🤖 NAGI BOT

**NAGI BOT** é um bot de WhatsApp moderno, rápido e modular, desenvolvido para **automação**, **administração de grupos**, **diversão** e **utilidades**.

Ideal para quem quer um bot **estável**, **personalizável** e fácil de manter.

---

## ✨ Funcionalidades

- 🤖 Sistema de comandos inteligente  
- 🎨 Criação de figurinhas  
- 🧠 Comandos com IA  
- 👥 Administração de grupos  
- 📥 Downloads (áudio / vídeo)  
- 🔊 Texto para fala (TTS)  
- 🌎 Tradução automática  
- ⚙️ Totalmente customizável
